# 莱纳八帧步行循环

## 接入

四方向各8帧，128×128透明PNG。map-data.js 的 walkDown / walkUp / walkLeft / walkRight 指向本目录。player-controller.js 每80ms推进一帧，仅实际移动成功时播放，转向重置循环，停步和碰撞恢复对应方向待机。原方向键优先级、地图、移动速度和碰撞框不变。

## 制作

侧面内侧靴子的残缺裁切已替换为外侧完整靴子图层，仅平移至内侧膝关节。两只靴子共用同一轮廓和原始颜色，内侧按相反步行相位播放。

采用现有 v2 待机角色作为固定造型，分离前后腿、上下腿和手臂，按相反相位驱动髋关节、膝关节和肩部。过渡帧有抬脚和1像素重心起伏。统一128画布，保持躯干宽高与装备稳定，避免每帧单独生成导致的比例变化。侧面靴子从折边以下整体缩至78%，保持鞋底高度；内侧与外侧共用鞋形。build.ps1 可重建32帧：传入 images/explore/player 的绝对路径作为 SpriteRoot；render-preview.cjs 可重建预览GIF。

内置 image_gen 曾尝试4×2整套帧生成；检查发现重复领先腿和镜头漂移，因此未采用。最终生产图使用现有造型的骨骼重定向。

动作循环参考：https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator 。未复制该项目的角色素材或代码。

preview.gif 是实际生产32帧组成的动态预览，依次为左、右、下、上，与游戏80ms帧间隔一致。contact-sheet.png 是全部帧对照。

## 检查

四方向均播放8帧；连按/松开方向键与重复键事件；停步；碰撞时待机；32张透明图尺寸；动态GIF8帧。通过逻辑与资产检查，未进行浏览器实机验证。
