# 剧情系统与素材接口

## Explore Mode 接口

总部试玩使用同一个 `gameState`，不保存玩家像素坐标。需要跨刷新保存的字段为：

- `mode`：`explore`、`dialog` 或 `minigame`
- `currentMap`：当前地图 ID，本阶段只有 `hq`
- `currentScene`：对话节点；探索时为 `null`
- `currentObjective`：HUD 显示的当前目标
- `flags`、`evidence`、`choices`、`minigameResults`：与剧情共用

地图配置位于 `js/explore/map-data.js`。地图、NPC、障碍和交互物都采用配置数据渲染；正式素材到位后不需要修改移动与碰撞代码。对话通过 `window.startDialog(sceneId)` 进入，带有 `returnToExplore: true` 的节点结束后自动恢复探索。

总部试玩流程：自由移动并调查 NPC/公告栏 → 与韩吉对话 → 设置 `hqIntroComplete` 和目标“前往玛利亚旧城区” → 从东侧出口进入 `chapter1_01`。本阶段没有实现贫民窟或档案室探索地图。

## 小游戏接入

小游戏通过 `window.TitanMinigames.registerMiniGame(type, handler)` 注册。处理函数可以返回普通对象或 Promise；剧情系统只读取结果，不允许小游戏直接控制剧情跳转。

```js
window.TitanMinigames.registerMiniGame("dodge", function () {
  return { type: "dodge", completed: true, success: true, score: 120 };
});
```

现有调用：

- `dodge`：第一章立体机动闪避，结果保存到 `minigameResults.dodge`。
- `investigation` + `scope: "slum"`：第二章地下街调查。证据 ID：`slum_list`、`slum_vial`、`slum_transport`、`slum_cross`、`slum_merchant`。
- `investigation` + `scope: "archive"`：第三章档案室调查。证据 ID：`archive_resource`、`archive_moat`、`archive_purge`、`archive_founder`。
- `memory`：第四章记忆排序，结果保存到 `minigameResults.memory`。
- `qte` + `scope: "broadcast"` 或 `scope: "founder_core"`：第五章最终行动。

调查小游戏成功时必须在结果的 `evidence` 数组中返回证据 ID。未实现的小游戏会返回 `status: "not_implemented"`，剧情自动进入可继续推进的替代流程。

## 建议补充的音频

背景音乐放入 `audio/bgm/`，建议同时提供 OGG 和 MP3；音效放入 `audio/sfx/`。优先补充心跳、巨人吼声、钟声、纸张翻动、立体机动和广播电流音效，以及噩梦、调查、记忆、决战和结局 BGM。

总部 Explore Mode 建议优先提供：

- `audio/bgm/hq.ogg` + `audio/bgm/hq.mp3`：总部低强度循环环境音乐，60–120 秒，无明显结尾，需可无缝循环。
- `audio/sfx/footstep-wood-01.ogg`、`02.ogg`：木地板脚步，两到四个短变体。
- `audio/sfx/interact.ogg`：通用确认音，0.1–0.4 秒。
- `audio/sfx/evidence.ogg`：获得线索提示音，0.5–1.5 秒。
- `audio/sfx/door.ogg`：总部出口木门开启声。

音频不是本阶段运行的必需项。补充时请确保拥有课程展示所需的使用授权，并尽量提供来源/作者信息，方便在项目说明中署名。
