# 四个结局：演出与对接

打开项目根目录的 endings.html，可直接观看或修改四个结局。

## 修改方式

编辑页面可以修改结局名称、片尾前的引句、每幕台词、角色名、画面、停留秒数和顺序。内心独白使用“独白”，角色名留空。图片替换路径从 images/ 开始。

好结局的“数月后”现在进入一张可操控地图。在编辑页下方的“数月后 · 探索地图与对话”中，可修改开场、五处交谈／查看、重复对话、离场对话、人物坐标和图片路径。与上面的演出一起保存、一起导出 good.js。详情见 [好结局探索尾声说明](DAWN-EPILOGUE.md)。

好结局新版草稿使用 v2 存储键。此前纯对白版的 v1 草稿原样保留，新版不会读取它；其他三个结局继续使用原有草稿。

“保存草稿”仅保存在当前浏览器，预览和该浏览器正式结局会优先使用草稿。“导出演出文件”后，用下载的 good.js / normal.js / bad.js / hidden.js 替换本目录同名文件，才会同步到其他浏览器与同学的项目。之后点击“恢复文件版本”清除本浏览器草稿；上一个草稿会保留在浏览器备份键中。

## 与触发流程的接口

| 固定剧情入口 | 演出文件 | 本版结局事实 |
| --- | --- | --- |
| ending_good_01 | good.js | 可信材料得到支持；广播成功，但马车中有人未能救出；莱纳接受审查，家属仍可能不原谅他。 |
| ending_normal_01 | normal.js | 优先救人并携证人、材料撤离；广播网络切断，匿名材料遭质疑，体系仍运转。 |
| ending_bad_01 | bad.js | 官方真的释放一批人、撤走监视兵、处分负责人；关键记录被删改或交出，莱纳证词成为结束追查的依据。 |
| ending_hidden_01 | hidden.js | 发现“已净化”者仍活着，核实运输日期、档案与记忆的矛盾；放弃现成广播窗口；接受自身追责，无一致认可。 |

入口 ID 不变。story.js 的四个入口新增 endingPresentation 字段；dialog.js 遇到字段会进入独立演出。入口前所有选择和判断仍由流程负责方修改。本次没有增加分数门槛、改变选择或结局优先级。

流程需要提前交代马车与广播的冲突、官方真实让步，以及隐藏路线可核实的矛盾，避免尾声凭空宣告损失。隐藏结局的这条具体矛盾链可协商替换，但需要同步 hidden.js 的对应幕；不要只做“多收集”的隐形评分。匿名路线的阻力应当可见，家属是否允许实名要延续到演出，不能自动给出全收益。条件不足应继续提供任务或补救选择，不自动进入普通结局。

## 节奏与片尾

每幕留有阅读停顿，文字淡出、淡入；结局最后先保留标题与余韵，再淡出音乐、进入黑幕，接 credits.html。四条路线共用已有片尾文字流；只按结局显示不同的开场标题和引句，没有复制四份字幕。

海岸目前使用可替换的渐变意境画面。可在编辑器填入正式海岸图片路径。音乐沿用项目现有 good_end.mp3，受原有音乐设置控制。

独立预览不写剧情存档。正式入口从 from=story 进入，完成后沿用四个结局标记及成就；演出不判断前置路线。
